# Security

Please report a vulnerability privately, through the repository's
Security tab:
[report a vulnerability](https://github.com/Mellow-Machines-Lab/MellowHarness/security/advisories/new).
Don't open a public issue for it.

These are in scope:

- **The log files**: what they hold, and who can read or change them.
- **The event socket** (`EventServer`): what can send events to it.
- **The Jev client** (`JevBrain`): what it sends to TypeSafe, and how.
